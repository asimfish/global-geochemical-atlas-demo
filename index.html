The Challenge · 赛题

赛题要求什么

气候与地球科学赛道赛题「全球地球化学元素分布图谱」：从公开数据出发，走完采集、处理、成图的完整链路，并识别异常区域。

01自动采集ACQUIRE

从公开文献与开源数据平台获取岩石、土壤、沉积物、水体四类介质的元素含量、采样坐标、地质背景与分析方法信息。

02科学处理STANDARDIZE

完成单位统一、空间匹配、质量控制、来源追溯。本项目在此基础上额外坚持一条：原始测定值永不覆盖，转换值另列保存。

03研究输出VISUALIZE

按元素 / 区域 / 地质单元 / 样品类型生成全球或区域分布图、热力图与元素组合对比，并识别异常富集与亏损区域。

赛题最终要求五项交付物。本项目不逐项拼装，而是由同一次 Skill 运行一次产出全部五项 → 看五项交付

同类数据库对比：此前不存在的一层

诚实前提：论绝对规模不与几十年机构积累竞争。同类库要么大而不统一（文献/档案汇编），要么统一而窄（单介质或单大洲）——跨源、跨介质、记录级可审计的统一层，是 GGA 补上的空位。对比数字全部来自公开页面与快照列级统计。

更全面 · 四介质两半球

同一 schema 覆盖土壤、沉积物、淡水与海水；五篇论文横跨欧洲、澳洲与全球大洋——同类产品均为单介质或单大洲。

更可靠 · 连缺失都可审计

100% 许可证 / SHA-256 / 置信度 / QC 覆盖；36.3% 缺方法的记录逐条记 missing_reason；删失保留不猜值——「缺什么」本身也是数据。

更统一 · 一晚跑通两大洲

P1→P2 用同一脚本框架、同一配对统计跑欧洲与澳洲，边际成本一个晚上；已知科学（欧洲 Hg/Pb 富集、GEOTRACES 营养盐剖面、跨调查 As 一致性）全部自动复现后才输出新问题。

科学边界：五篇论文全部为筛查级结论（screening-level）：富集 ≠ 污染定论，剖面形态 ≠ 机制证明；五篇均已通过 a–g 七项质量审计（数据合理性 / 叙述一致 / 排版 / 数据完整 / 术语规范 / 图表规范 / 表格规范），正式投稿前仍需领域专家人工复核；全部数字可由冻结快照 + 种子脚本确定性重放。完整路线图见 five-paper-roadmap.md，对比出处见 database-comparison.md。
