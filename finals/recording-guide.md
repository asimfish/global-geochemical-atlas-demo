# Demo 视频正式录制指南

## 推荐成片

- 时长：`02:50–03:00`；
- 画面：1920×1080，30 fps，16:9；
- 视频：H.264，12–16 Mbps，`yuv420p`；
- 音频：AAC，48 kHz，192 kbps；
- 文件名：`TEAM0066-Global-Geochemical-Atlas-Demo.mp4`。

## 录制前

1. 在 `Global-Geochemical-Atlas-Demo/` 运行 `python3 start_demo.py`。
2. 用 Chrome/Edge 打开 `/finals/demo-video.html`，切到第 6 幕，把右上四个视图标签（全球图谱 74MB / 3D 地球 / 全球总览 / 中国区异常）各点开预热一次。
3. 关闭通知、聊天软件悬浮窗和浏览器书签栏。
4. 浏览器缩放保持 100%，按 `F` 全屏。
5. 用 `← / →` 走一遍，确认中文字体、二维码、地图和动画正常。
6. 录音峰值控制在 -12 至 -6 dB，环境底噪低于 -45 dB。

目录中的 `Global-Geochemical-Atlas-Final-Demo-Silent-Preview.mp4` 是画面节奏参考，不是建议直接提交的最终有声版。可将真人旁白按 `speaker-script.md` 录成一条 WAV，再在剪辑软件中替换静音音轨。

## 录制

1. 开始屏幕录制后静置 1 秒。
2. 按 `R` 从头启动计时。
3. 按 `speaker-script.md` 口播；第 5 幕日志以约 78 倍速回放真实运行（76 行全真日志，约 26 秒滚完），边滚边讲，按 `L` 可重放；第 6 幕点击右上标签进入真实交互产物，至少演示全球图谱。
4. 结束页停 2 秒再停止录制。

## 交互失败降级

若现场机器载入卡顿，不要临时等待：点右上「截图」标签（或按 `I`）回到静态高分辨率截图，按讲稿完成。静态画面仍然来自真实运行产物，不是设计稿。

## 后期检查

- 总时长不超过 3 分钟；
- 结构为两段式：00:00–01:00 讲计划与设计，01:00–03:00 为 Agent 真实运行记录与实际使用；
- 01:00–01:36 为全球在线运行的日志回放（33 分钟真实运行、9 轮、191,715 条），01:36–02:00 现场演示图谱产物与多视图切换；
- 全球运行与回归运行数字不得混用（见讲稿末尾检查清单）；
- 所有统计口径与 Poster/PPT 一致；
- “候选异常”未被说成污染、矿床或成因结论；
- 二维码至少停留 2 秒并可扫码；
- 仓库与 Demo 链接可访问；
- 导出后在另一台设备完整播放一次。

## FFmpeg 最终压制

```bash
ffmpeg -i recording-master.mov \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ar 48000 \
  -movflags +faststart \
  TEAM0066-Global-Geochemical-Atlas-Demo.mp4
```
