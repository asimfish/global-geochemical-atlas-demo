数据库语义

一行 = 一个样品的一项元素测定；同一样品测多种元素时占多行，统计采样点数应使用“物理采样点”而非行数。每行同时保留原始值与标准化值（含单位），并关联样品类型、测量基准、地质单元、分析方法、WGS84 坐标、数据来源与质量标记。

数据修订

在左侧表格选择记录后，可在此提出新增、修改或排除建议。修订不直接改动数据文件：导出的 JSON 修订包经数据管线复核后统一执行，原始数据与证据始终保留。

元素组合对比

分析同一样品中两种元素的共变关系。左侧矩阵给出常见元素组合的 Spearman 相关系数，点击任意组合查看配对散点；只比较同介质、同测量基准、同方法的可比测定。

元素相关性矩阵 · Spearman ρ

红色为正相关、蓝色为负相关，颜色越深关联越强；基于同一样品的可比配对计算，配对不足 8 对时不给出系数。点击任意组合查看散点。

可比样品配对散点

橙色实线为对数空间线性趋势，虚线为两轴中位数；Spearman ρ 描述单调关联，不证明因果或来源。

异常区域识别结果
